#+title: Afternoon Theme for Neovim

[[file:afternoon-theme-title.png]]

* Overview

Afternoon is a dark Neovim colorscheme with a deep charcoal background and
blue-toned syntax colors. It is a Lua port of
[[https://github.com/ozanvos/emacs-afternoon-theme][emacs-afternoon-theme]].

* Note on the port

This port is made with respect for the original Emacs theme and aims to
reproduce it as faithfully as possible. Some details are difficult to reproduce
in Neovim, however, and a few choices have been adjusted to reflect personal
preference.

* Installation

Add this repository to your Neovim runtime path with your plugin manager, then
enable the colorscheme:

#+begin_src lua
vim.cmd.colorscheme("afternoon")
#+end_src

** lazy.nvim

With [[https://github.com/folke/lazy.nvim][lazy.nvim]]:

#+begin_src lua
{
  "tamajio/afternoon-theme-neovim",
  priority = 1000,
  config = function()
    vim.cmd.colorscheme("afternoon")
  end,
}
#+end_src

** Neovim 0.12 or later

Neovim 0.12 includes the built-in [[https://neovim.io/doc/user/pack.html][vim.pack]]
plugin manager. Add the plugin to =init.lua= and restart Neovim:

#+begin_src lua
vim.pack.add({
  "https://github.com/tamajio/afternoon-theme-neovim",
})

vim.cmd.colorscheme("afternoon")
#+end_src

Use =:checkhealth vim.pack= and =:help vim.pack= for setup and update commands.

** vim-plug

With [[https://github.com/junegunn/vim-plug][vim-plug]], add the plugin to your
=init.vim= and run =:PlugInstall=:

#+begin_src vim
call plug#begin()
Plug 'tamajio/afternoon-theme-neovim'
call plug#end()

colorscheme afternoon
#+end_src

For Lua-based =init.lua=, the Vimscript block can be written as:

#+begin_src lua
vim.cmd([[
call plug#begin()
Plug 'tamajio/afternoon-theme-neovim'
call plug#end()
]])

vim.cmd.colorscheme("afternoon")
#+end_src

* Requirements

The colorscheme itself has no required plugin dependencies. To use the
Java/Lua variable declaration and assignment highlights, install
[[https://github.com/nvim-treesitter/nvim-treesitter][nvim-treesitter]] and its
=java= and =lua= parsers (for example, with =:TSInstall java= and
=:TSInstall lua=).

* Code layout

- =colors/afternoon.lua=: Neovim colorscheme entry point.

** Core Lua modules

- =lua/afternoon/init.lua=: public setup API and colorscheme initialization.
- =lua/afternoon/config.lua=: configuration defaults and merged options.
- =lua/afternoon/palette.lua=: shared palette used across highlight modules.
- =lua/afternoon/terminal.lua=: terminal ANSI colors.

** Highlight modules

- =lua/afternoon/highlights/init.lua=: loads highlight modules and applies user overrides.
- =lua/afternoon/highlights/base.lua=: core editor UI and window elements.
- =lua/afternoon/highlights/syntax.lua=: standard Vim syntax groups.
- =lua/afternoon/highlights/git.lua=: Git diff and GitSigns groups.
- =lua/afternoon/highlights/lsp.lua=: diagnostics and generic LSP groups.
- =lua/afternoon/highlights/treesitter.lua=: common Tree-sitter highlight links.
- =lua/afternoon/highlights/org.lua=: =org.nvim= document and agenda groups.
- =lua/afternoon/highlights/neogit.lua=: =Neogit= groups and commit bracket highlighting.
- =lua/afternoon/highlights/neotree.lua=: =neo-tree.nvim= groups.
- =lua/afternoon/highlights/trouble.lua=: =Trouble.nvim= groups.

** Language-specific modules

- =lua/afternoon/highlights/lsp/java.lua=: Java-specific LSP semantic tokens.
- =lua/afternoon/highlights/lsp/lua.lua=: Lua-specific LSP semantic tokens.
- =lua/afternoon/highlights/treesitter/java.lua=: Java-specific Tree-sitter captures.
- =lua/afternoon/highlights/treesitter/lua.lua=: Lua-specific Tree-sitter captures.
- =lua/afternoon/highlights/treesitter/bash.lua=: Bash-specific Tree-sitter captures.

** Query overrides

- =queries/java/highlights.scm=: custom Java declaration and assignment captures.
- =queries/lua/highlights.scm=: custom Lua declaration and assignment captures.

* Customization

Call =setup= before loading the colorscheme. =palette= overrides shared color
values; =highlight_groups= overrides individual Neovim highlight groups.

#+begin_src lua
require("afternoon").setup({
  palette = {
    orange = "#ff9e64",
  },
  highlight_groups = {
    Normal = { bg = "#101018" },
    ["@lsp.type.modifier.java"] = { fg = "#00bfff" },
  },
})

vim.cmd.colorscheme("afternoon")
#+end_src
