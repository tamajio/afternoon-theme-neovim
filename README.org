#+title: Afternoon Theme for Neovim

* Overview

Afternoon is a dark Neovim colorscheme with a deep charcoal background and
blue-toned syntax colors. It is a Lua port of
[[https://github.com/ozanvos/emacs-afternoon-theme][emacs-afternoon-theme]].

* Note on the port

This port is made with respect for the original Emacs theme and aims to
reproduce it as faithfully as possible. Some details are difficult to reproduce
in Neovim, however, and a few choices have been adjusted to reflect personal
preference.

* Installation

Add this repository to your Neovim runtime path with your plugin manager, then
enable the colorscheme:

#+begin_src lua
vim.cmd.colorscheme("afternoon")
#+end_src

For example, with lazy.nvim:

#+begin_src lua
{
  "tamajio/afternoon-theme-neovim",
  priority = 1000,
  config = function()
    vim.cmd.colorscheme("afternoon")
  end,
}
#+end_src

* Requirements

The colorscheme itself has no required plugin dependencies. To use the
Java/Lua variable declaration and assignment highlights, install
[[https://github.com/nvim-treesitter/nvim-treesitter][nvim-treesitter]] and its
=java= and =lua= parsers (for example, with =:TSInstall java= and
=:TSInstall lua=).

* Migration status

This checklist tracks highlight coverage implemented by this colorscheme; it
does not indicate complete feature support in the related plugins.

** Org mode

=org.nvim= provides Org syntax support; this colorscheme supplies the Org mode
and agenda highlight groups.

- [X] Headline levels, TODO/DONE states, priorities, and tags.
- [X] Timestamps, planning, links, blocks, code, tables, footnotes, and LaTeX.
- [X] Document title.
- [ ] Document info and info-keyword colors.
- [ ] Folded markers and hidden text (=org-ellipsis= / =org-hide=).
- [ ] Warning faces.

** Org agenda

- [X] Structure header, dates, completed items, and dimmed items.
- [X] Scheduled items and deadlines.
- [ ] Column view and column-title colors.

** Languages and editor highlights

- [X] Core Neovim UI and standard syntax highlight groups.
- [X] Tree-sitter links for common syntax and markup captures.
- [X] Java and Lua Tree-sitter captures for variable declarations and assignments.
- [X] LSP diagnostic severity colors and Java-specific semantic-token mappings.
- [ ] Custom Tree-sitter declaration and assignment captures for languages beyond Java and Lua.
- [ ] Language-specific LSP semantic-token mappings beyond Java.

** Git, plugins, and terminal

- [X] Git diff and GitSigns highlights.
- [X] Neogit highlights based on the original theme's Magit faces, including
  commit bracket accents.
- [X] =neo-tree.nvim= file and directory highlights.
- [X] Neovim diagnostic groups carry the Emacs Flycheck error and warning colors; =Trouble.nvim= reuses them for diagnostic severity markers.
- [X] =Trouble.nvim= uses the base background, orange folder icons and names, purple filenames, sky-blue diagnostic codes, and gray hierarchy lines.
- [X] Terminal ANSI colors.

* Code layout

- =colors/afternoon.lua=: Neovim colorscheme entry point.
- =lua/afternoon/palette.lua=: shared color palette.
- =lua/afternoon/highlights/base.lua= and =syntax.lua=: editor UI and syntax.
- =lua/afternoon/highlights/git.lua= and =lsp.lua=: Git and diagnostics/LSP.
- =lua/afternoon/highlights/org.lua=: =org.nvim= highlight groups.
- =lua/afternoon/highlights/neogit.lua=: =Neogit= highlight groups.
- =lua/afternoon/highlights/neotree.lua=: =neo-tree.nvim= highlight groups.
- =lua/afternoon/highlights/trouble.lua=: =Trouble.nvim= highlight groups.
- =lua/afternoon/highlights/treesitter.lua=: Tree-sitter highlight links.
- =lua/afternoon/terminal.lua=: terminal ANSI colors.
- =queries/java/= and =queries/lua/=: Tree-sitter variable declaration and
  assignment captures.

* Customization

Call =setup= before loading the colorscheme. =palette= overrides shared color
values; =highlight_groups= overrides individual Neovim highlight groups.

#+begin_src lua
require("afternoon").setup({
  palette = {
    orange = "#ff9e64",
  },
  highlight_groups = {
    Normal = { bg = "#101018" },
    ["@lsp.type.modifier.java"] = { fg = "#00bfff" },
  },
})

vim.cmd.colorscheme("afternoon")
#+end_src
